# Task: Create Translation Dictionaries

## Files Created

### `generate_translations.py`

- Created a script to programmatically generate `.po` and `.mo` files for the UI translations.
- This script uses the `polib` library to create the translation files for English, Persian, Arabic, and Turkish.

## Terminal Commands

The following command should be executed in a PowerShell terminal:

```pwsh
python generate_translations.py
```
